# 🔐 Escape Room del laboratorio

## Descripción
El objetivo de la práctica es crear un juego de escape con tres salas cerradas, que solo se podrán abrir si se resuelven una serie de retos manipulando las estructuras de datos empleadas en la unidad. 

Para cambiar de pantalla se podrá emplear `window.location.href` o `window.location.reload()`  en caso de tener que recargar la misma pantalla.

---

## Salas y retos 
Cada una de las salas tendrá como requisito emplear las siguientes herramientas: 

### 1. Sala 1: El despacho

- Tendrá algún objeto con propiedades de tipos de datos simples y al menos una propiedad con funciones y otra con objetos anidados. 
- Se usarán métodos de clonación de objetos al menos una vez.

### 2. Sala 2: La sala de control

Empleará las siguientes herramientas: 

- Al menos tres métodos de Arrays 
- Un Map y Set para almacenar pistas.  
- Se aplicará al menos una vez el operador spread.
- Se aplicará al menos una vez la desestructuración.
- Se usará Array.from para convertir claves o valores a un Array.

### 3. Sala 3: El laboratorio central

Empleará las siguientes herramientas: 

- Creará alguna clase con herencia, propiedades o métodos privados y 
estáticos. 
- Todas las clases se guardarán en módulos y se importarán posteriormente. 

---
Por otro lado, a nivel general se requiere controlar excepciones al menos una vez en alguna de las salas.
